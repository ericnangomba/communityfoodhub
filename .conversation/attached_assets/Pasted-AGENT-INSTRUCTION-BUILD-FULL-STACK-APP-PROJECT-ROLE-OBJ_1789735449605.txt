AGENT INSTRUCTION: BUILD FULL-STACK APP
PROJECT ROLE & OBJECTIVE
You are an expert full-stack engineer and UI/UX designer. Your task is to build a mobile-first, production-ready Web Application and Real-Time Admin Dashboard for a localized food distribution network: the Community Wealth Hub Platform (Pilot: Elsies River, Western Cape).However include all Western Cape Ward Zone for easy scalability in the future

The project counters retail monopolies by enabling localized micro-repackaging and distribution of essential foods. It connects community clients, local suburban hubs, central warehouses, and delivery agents while keeping wealth circulating within the community.The essential food price baseline should be currently in main retail outlets but the sysytem must calculate in the super admin to offset the main retailers price. The super admin initiates the algorithm and gets to the hub to apply or the super admin applies the offset prices immediately the algorithm is done calculating , then the price is published on the consumer frontend /online front which the consumers sees when ordering food .

TECH STACK REQUIREMENTS
Frontend Framework: React or Next.js (TypeScript) with Tailwind CSS.

UI Components & Icons: Shadcn/UI, Lucide Icons, and Recharts (for analytics).

Backend/Database: Node.js/Express OR Supabase/PostgreSQL (with spatial location support).

Messaging Mock/Integration: WhatsApp Webhook/API handler for receiving & processing automated WhatsApp text orders.

State & Data Management: React Query / TanStack Query.

CORE ARCHITECTURE & DATA SCHEMAS
Create a relational database schema supporting the following tables:

users -> id, full_name, phone_number, role (SUPER_ADMIN, HUB_ADMIN, WAREHOUSE_MGR, DELIVERY_AGENT, CLIENT), hub_id.

hubs -> id, hub_name (e.g., "Elsies River Hub", "Southern Suburbs Hub"), region, status.

warehouses -> id, hub_id, warehouse_name, address.

inventory -> id, warehouse_id, item_name, package_size (e.g., "500g", "1kg"), unit_price, stock_quantity, reorder_threshold.

orders -> id, client_id, hub_id, agent_id, order_source (WEB_APP, WHATSAPP), status (PENDING, WAREHOUSE_PACKING, DISPATCHED, DELIVERED), total_amount, created_at.

analytics_logs -> id, event_type, metric_value, metadata, created_at.

KEY MODULES TO BUILD
1. Role-Based Access Control (RBAC) & Authentication
Build an authentication screen with role-switching or user login logic to demonstrate perspectives for: Super Admin, Hub Admin, Delivery Agent, and Community Client.
2. Multi-Channel Ordering Interface (Client-Facing)
Mobile-first Web App layout for clients in Elsies River.

Responsive store catalog showing repackaged, essential food items with prices.

Shopping cart, checkout flow, and delivery address selection.

WhatsApp Simulator: A UI widget that simulates a client placing an order via a WhatsApp message (e.g., texting "Order 2x 1kg Rice to Elsies River Block B"), which automatically parses and creates an entry in the Hub's pending orders queue.

3. Central Hub & Logistics Dispatch Module
Hub order-processing view: Incoming orders (Web + WhatsApp) arrive at the Hub.

Automated inventory availability check against local Warehouse stock.

One-click dispatch: Assign an active Delivery Agent to collect packaged goods from the warehouse and deliver them to the client.

4. Delivery Agent Interface
Simplified mobile portal for agents showing assigned deliveries, pickup warehouse details, drop-off client locations, and a "Confirm Delivery" action button.
5. Integrated Command Dashboard & Built-in AI Analytics (Super Admin View)
Build an executive dashboard containing:

System-Wide Operational Control: Unified view monitoring all regional suburban hubs, active orders, agent turnarounds, and real-time inventory levels across warehouses.

Automated Inventory Replenishment Alert System: Visual triggers and auto-reorder suggestions when warehouse stock dips below predefined thresholds.

Built-in AI Analytics Engine:

Consumer Behavior & Pattern Recognition Card: Generates predictive insights on peak purchasing times, popular repackaged items, and localized purchasing habits across suburbs.

Predictive Demand & Stock Forecasting: AI-assisted replenishment models predicting stock depletion before running out.

Socio-Economic Wealth Retention Tracker: Metrics displaying total local currency retained within Elsies River vs. lost to corporate chains, along with community service delivery reinvestment totals.
